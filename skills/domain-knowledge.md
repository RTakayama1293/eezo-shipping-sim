# EEZO送料ロジック ドメイン知識

## 3層構造の相互作用

### なぜ3層か

送料問題は「顧客体験」と「事業者利益」のトレードオフ。
- 送料無料にすると粗利が飛ぶ
- 送料を正直に表示すると、北海道発の冷凍便は高く見え、離脱する
- 商品に全額転嫁すると、市場価格との乖離が大きすぎる

3層に分散することで、どの層も「ちょっとずつ」負担し、全体として成立させる。

### 損益の数式

```
顧客支払額 = Σ(販売価格) + 固定送料 - 割引額
事業者コスト = Σ(仕入原価) + 実配送コスト
粗利 = 顧客支払額 - 事業者コスト
粗利率 = 粗利 / 顧客支払額
```

### 実配送コストの決まり方

- 同一仕入先・同一温度帯 → 同梱可能 → 1口分
- 異なる仕入先 → 別発送 → 口数分
- 温度帯混在（冷凍+常温） → 原則別口だが、常温品を冷凍便に同梱するケースもある
- サイズはSKU重量の合算で判定（60/80/100/120サイズ）

### 同梱サイズ判定ルール（簡易版）

| 合計重量 | サイズ |
|---------|--------|
| 〜2kg | 60 |
| 2〜5kg | 80 |
| 5〜10kg | 100 |
| 10〜15kg | 120 |

※実際は体積も関係するが、食品の密度を考慮するとほぼ重量で決まる

## Shopifyでの実装制約

### 自動ディスカウント
- 1注文につき1つのみ
- 条件: 金額しきい値、商品数、商品コレクション等
- 「同一仕入先から2品以上」は直接設定不可 → コレクション（仕入先別）で代替

### Shipping Profile
- 地域別・商品別に送料設定可能
- 重量ベースの送料設定も可能
- ただし「1口あたり」の概念がないため、追加送料の制御が難しい

### 実装パターン（推奨）
1. Shipping Profileで全国一律1,000円を設定
2. 商品をコレクション（仕入先別）で分類
3. 自動ディスカウントで「コレクション内2品以上で○円引き」を設定
4. 段階割引は最も発生頻度の高いパターンに絞る

## 価格設定の参考値

### 新日本海商事の粗利基準（BtoB）
| 区分 | 国内 | 海外 |
|------|------|------|
| 単純仕入 | 20% | 30% |
| 定型加工 | 25% | 35% |
| 特注加工 | 30% | 40% |

### BtoCでの考え方
- BtoBの20%をベースに、送料転嫁分を上乗せ
- 粗利15%が絶対下限（赤字にならない最低ライン）
- 送料は基本的に利益ゼロで右から左へ流す方針
